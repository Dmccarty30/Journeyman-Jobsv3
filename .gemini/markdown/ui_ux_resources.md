### Core Design

- **aesthetic**: Comprehensive framework for beautiful interfaces (Beautiful, Right, Satisfying, Peak).
- **frontend-design**: Web UI design thinking and decision making.
- **mobile-design**: Mobile-first design patterns.
- **ui-ux-pro-max**: Advanced design intelligence, anti-cliché rules, and "Deep Design Thinking".

### Implementation & Frameworks

- **ui-styling**: Implementation using Tailwind CSS and shadcn/ui.
- **tailwind-patterns**: Tailwind v4 principles and best practices.
- **react-patterns**: Modern React patterns, hooks, and performance.
- **nextjs-best-practices**: App Router, server components, and architecture.

- **webapp-testing**: E2E testing with Playwright (critical for UI verification).

- **seo-fundamentals**: Core Web Vitals and frontend metadata.
- **accessibility-checker** (Script in frontend-design): Automated a11y checks.
